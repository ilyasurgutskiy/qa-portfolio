# BUG-001 — Avito

**Title:** Кнопка "Назад" в мобильном браузере открывает страницу 404 вместо возврата к списку объявлений продавца

## Steps to Reproduce
1. Открыть профиль продавца с несколькими объявлениями
2. Пролистать список объявлений вниз
3. Открыть любое объявление
4. Нажать кнопку "Назад" в браузере

## Expected Result
Пользователь возвращается на страницу продавца к списку объявлений

## Actual Result
Отображается страница с ошибкой "Такой страницы не существует" (404)

## Details
- **Severity:** Major
- **Priority:** High
- **Device:** iPhone 16
- **OS:** iOS
- **Browser:** Safari Mobile
- **Network:** Мобильный интернет (4G/5G)
- **Note:** На WiFi баг не воспроизводится
