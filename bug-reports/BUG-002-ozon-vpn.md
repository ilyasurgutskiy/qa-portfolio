# BUG-002 — Ozon VPN

**Title:** Приложение Ozon не работает при включённом VPN

## Steps to Reproduce
1. Включить VPN на устройстве
2. Открыть приложение Ozon
3. Ввести любой запрос в поисковую строку

## Expected Result
Приложение отображает результаты поиска

## Actual Result
Отображается страница "Нет подключения к интернету"

## Details
- **Severity:** Minor
- **Priority:** Low
- **Device:** iPad Pro M2
- **OS:** iPadOS
- **App version:** 19.30.0
- **Network:** WiFi + VPN
