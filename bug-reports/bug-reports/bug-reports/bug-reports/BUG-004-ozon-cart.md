# BUG-004 — Ozon корзина

**Title:** Товар добавленный в корзину отображается как "Нет в наличии"

## Steps to Reproduce
1. Открыть приложение Ozon
2. Найти футболку поло Adidas через поиск
3. Добавить товар в корзину
4. Перейти в корзину

## Expected Result
Товар отображается как доступный для заказа

## Actual Result
Товар отображается со статусом "Нет в наличии"

## Details
- **Severity:** Major
- **Priority:** High
- **Device:** iPad Pro M2
- **OS:** iPadOS
- **App version:** 19.30.0
- **Network:** WiFi
