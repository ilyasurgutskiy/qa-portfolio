# TC-001 — Поиск товара на Ozon

**Title:** Позитивный сценарий работы поисковой строки

**Preconditions:**
- Приложение Ozon установлено и открыто
- Пользователь авторизован
- Есть подключение к интернету

## Steps
1. Открыть приложение Ozon
2. Нажать на поисковую строку
3. Ввести запрос "Джинсы"
4. Нажать кнопку "Найти"

**Expected Result:** Отображается список товаров категории джинсы с фото, ценами и названиями

**Status:** Pass
