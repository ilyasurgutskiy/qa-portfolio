# TC-002 — Добавление товара в корзину Ozon (позитивный)

**Title:** Пользователь успешно добавляет товар в корзину

**Preconditions:**
- Приложение Ozon установлено и открыто
- Пользователь авторизован
- Есть подключение к интернету

## Steps
1. Открыть приложение Ozon
2. Найти любой товар через поиск
3. Нажать кнопку "Добавить в корзину"
4. Перейти в корзину

**Expected Result:** Товар отображается в корзине как доступный для заказа

**Status:** Pass
