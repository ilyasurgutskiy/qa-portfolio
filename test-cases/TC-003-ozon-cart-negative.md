# TC-003 — Оформление заказа с пустой корзиной (негативный)

**Title:** Пользователь пытается оформить заказ с пустой корзиной

**Preconditions:**
- Приложение Ozon установлено и открыто
- Пользователь авторизован
- Корзина пустая

## Steps
1. Открыть приложение Ozon
2. Перейти в корзину
3. Убедиться что корзина пустая
4. Проверить наличие кнопки "Заказать"

**Expected Result:** Кнопка "Заказать" недоступна или отсутствует, отображается сообщение о пустой корзине

**Status:** Pass
