# TC-004 — Вход в аккаунт Ozon (позитивный)

**Title:** Пользователь успешно входит в аккаунт

**Preconditions:**
- Приложение Ozon установлено и открыто
- Пользователь не авторизован
- Есть зарегистрированный аккаунт

## Steps
1. Открыть приложение Ozon
2. Нажать кнопку "Войти"
3. Ввести корректный email
4. Ввести корректный пароль
5. Нажать кнопку "Войти"

**Expected Result:** Пользователь успешно авторизован и попадает на главную страницу

**Status:** Pass
