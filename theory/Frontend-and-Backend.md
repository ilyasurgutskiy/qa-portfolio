# 🍽️ Фронтенд и Бэкенд простыми словами

> Объяснение для тех, кто только начинает.  
> Представь, что сайт или приложение — это **ресторан**.

---

## 🍽️ Фронтенд — это зал для гостей

Ты заходишь в ресторан, садишься за столик, видишь меню, кнопки, картинки, анимации.  
Это всё, что **ты видишь и можешь потрогать**.

Фронтенд — это **лицо** сайта.  
Он говорит: «Нажми сюда! Посмотри туда!»

Примеры фронтенда:
- HTML
- CSS
- JavaScript
- React, Vue, Angular

---

## 👨‍🍳 Бэкенд — это кухня

А вот кухня спрятана за дверью. Ты её не видишь.  
Там повара готовят еду, моют овощи, хранят продукты.

Бэкенд — это **мозг и кухня** сайта. Он:
- решает, что делать;
- проверяет, можно ли тебе это;
- сохраняет данные;
- считает;
- достаёт информацию.

Примеры бэкенда:
- Python (Django, FastAPI, Flask)
- Node.js (Express, NestJS)
- Java (Spring)
- Go
- PHP (Laravel)

---

## 🧑‍🍳 API — это официант

Между залом и кухней бегает официант.  
Он передаёт заказы туда и еду обратно.

В компьютере это называется **API**.

API помогает фронтенду и бэкенду общаться друг с другом.

---

## 🗄️ База данных — это кладовая

На кухне есть большой шкаф с продуктами.  
Там хранятся все данные: имена, пароли, лайки, сообщения.

Это **база данных**.

Примеры баз данных:
- PostgreSQL
- MySQL
- SQLite
- MongoDB

---

## 🔄 Как это работает вместе

1. Ты нажимаешь кнопку «Заказать пиццу».
2. Фронтенд отправляет запрос через API.
3. Бэкенд принимает запрос и идёт в базу данных.
4. База данных возвращает нужные данные.
5. Бэкенд готовит ответ.
6. API передаёт ответ фронтенду.
7. Фронтенд показывает результат: «Пицца едет!»

---

## 📊 Краткая таблица

| Часть          | Роль                          | Аналогия               |
|----------------|-------------------------------|------------------------|
| Фронтенд       | То, что видит пользователь    | Зал для гостей         |
| Бэкенд         | Логика и обработка данных     | Кухня                  |
| API            | Связь между фронтом и бэком   | Официант               |
| База данных    | Хранение информации           | Кладовая               |

---

## 🎯 Итог

- **Фронтенд** — то, что ты видишь и нажимаешь.
- **Бэкенд** — то, что работает за кулисами.
- **База данных** — где всё хранится.
- **API** — официант, который их соединяет.

Без фронтенда ты бы не понял, куда нажимать.  
Без бэкенда кнопки бы ничего не делали.  
А вместе — получается сайт или игра! 🎉
