# Agile и Scrum — Шпаргалка QA

## Waterfall vs Agile

| | Waterfall | Agile |
|---|---|---|
| Принцип | Последовательно | Итерациями |
| Тестирование | В конце | На каждом этапе |
| Гибкость | Низкая | Высокая |

## Ключевые понятия Scrum

| Термин | Описание |
|---|---|
| Sprint | Итерация разработки, обычно 2 недели |
| Backlog | Список всех задач продукта |
| Daily Standup | Ежедневная встреча команды 15 минут |
| Retro | Встреча в конце спринта — что улучшить |
| Planning | Планирование следующего спринта |

## Роль QA в Agile

- Участвует в планировании спринта
- Тестирует задачи внутри спринта параллельно с разработкой
- Пишет тест-кейсы параллельно с разработкой
- Участвует в Daily Standup каждый день
- Участвует в Retro в конце спринта

## Типичный день QA в Agile

1. Daily Standup — 15 минут
2. Тестирование задач текущего спринта
3. Написание баг-репортов
4. Общение с разработчиками
5. Обновление статусов в Jira
