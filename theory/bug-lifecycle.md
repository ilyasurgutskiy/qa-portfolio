# Жизненный цикл бага — Шпаргалка QA

## Статусы по порядку

New → Assigned → In Progress → Fixed → Retest → Closed / Reopened

## Описание статусов

| Статус | Кто | Описание |
|---|---|---|
| New | Тестировщик | Баг найден и заведён в систему |
| Assigned | Тимлид | Баг назначен разработчику |
| In Progress | Разработчик | Разработчик чинит баг |
| Fixed | Разработчик | Разработчик говорит что починил |
| Retest | Тестировщик | Тестировщик перепроверяет |
| Closed | Тестировщик | Баг подтверждён исправленным |
| Reopened | Тестировщик | Баг не исправлен, возвращается |

---

## Дополнительные статусы

| Статус | Описание |
|---|---|
| Won't Fix | Баг подтверждён но исправлять не будем |
| Duplicate | Баг уже заведён другим тестировщиком |
| Need Info | Нужна дополнительная информация |
