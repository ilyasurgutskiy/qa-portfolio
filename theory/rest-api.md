# REST API — Шпаргалка QA

## Что такое REST API

REST API — архитектурный стиль взаимодействия клиента
с сервером по протоколу HTTP.
Данные передаются в формате JSON.

## HTTP Методы

| Метод | Действие | Пример |
|---|---|---|
| GET | Получить данные | Загрузить список товаров |
| POST | Создать новый объект | Зарегистрировать пользователя |
| PUT | Обновить существующий | Изменить профиль |
| DELETE | Удалить | Удалить аккаунт |

## HTTP Коды ответов

| Код | Название | Описание |
|---|---|---|
| 200 | OK | Запрос выполнен успешно |
| 201 | Created | Объект успешно создан |
| 400 | Bad Request | Неверный запрос |
| 401 | Unauthorized | Нужна авторизация |
| 403 | Forbidden | Доступ запрещён |
| 404 | Not Found | Ресурс не найден |
| 500 | Internal Server Error | Ошибка сервера |

## Структура запроса

- URL — адрес запроса
- Метод — GET / POST / PUT / DELETE
- Headers — заголовки (токен авторизации)
- Body — тело запроса (только у POST и PUT)

## Что тестировщик проверяет в API

1. Позитивные сценарии — верный запрос → верный ответ
2. Негативные сценарии — пустые поля, неверные данные
3. Граничные значения — минимум и максимум
4. Авторизация — запрос без токена → 401
5. Формат данных — число вместо строки
