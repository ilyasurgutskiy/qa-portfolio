# Виды тестирования — Шпаргалка QA

## По знанию системы

| Вид | Описание |
|---|---|
| Чёрный ящик | Тестируем не зная внутреннего устройства |
| Белый ящик | Тестируем зная код и внутреннюю структуру |
| Серый ящик | Частичное знание внутреннего устройства |

## По цели

| Вид | Описание |
|---|---|
| Функциональное | Проверяем что система делает то что должна |
| Регрессионное | Новые изменения не сломали старый функционал |
| Smoke | Быстрая проверка что система вообще работает |
| Нагрузочное | Система работает при ожидаемой нагрузке |
| Стрессовое | Система при превышении лимитов нагрузки |
| Юзабилити | Удобство использования интерфейса |
| Безопасности | Защита данных и уязвимости |
| Совместимости | Работа на разных устройствах и браузерах |

---

## Быстрое правило

- **Функциональное** — что система делает
- **Нефункциональное** — как хорошо она это делает
